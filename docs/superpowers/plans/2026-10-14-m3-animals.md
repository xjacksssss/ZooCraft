# M3 Animals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Animals are recognised automatically, grouped into exhibits, chosen and viewed by visitors, and visitors' reactions feed comments, satisfaction and reputation (spec section 8).

**Architecture:** Pure rules in `com.zoocraft.core` (recognition decision, exhibit grouping, exhibit choice) with JUnit tests. A per-zoo `AnimalCensus` runs one entity query every `censusIntervalSeconds` and caches animals and exhibits; visitors only ever read that cache. Species identity comes from the entity type, merged by the NeoForge data map `zoocraft:species`. Include and exclude lists are entity type tags.

**Tech Stack:** NeoForge data maps, entity type tags, `BlockGetter.traverseBlocks` for the single viewing ray.

**Spec:** `docs/superpowers/specs/2026-10-14-phase1-prototype-design.md` (section 8)

**Execution note:** The user asked for uninterrupted execution. Plans list exact files, interfaces and tests; code is written during execution, test first where the logic is pure.

## Global Constraints

- No per-visitor world scans: viewing reads the census cache only, at most 8 nearest animals per check.
- Unknown animals get no invented requirements.
- Welfare checks are out of scope; the only exhibit warning is "can't get close enough".

## Review Focus

- A mod entity that extends `Animal` but spawns as MONSTER (for example hoglins): excluded unless tagged in. JUnit.
- Babies and colour variants: one species. GameTest with a baby and adult pig gives one species.
- Animals behind glass count, behind stone don't. GameTest.
- An exhibit nobody can reach: visitors stop choosing it for a while and it is flagged. Covered by `Exhibit.markUnreachable` and the dashboard warning.
- A zoo with no animals: visitors say "There aren't any animals to see." once and leave sooner. Covered by the controller path; checked in the play-test.

### Task 1: Pure rules

**Files:**
- Create: `core/animal/RecognitionFacts.java`, `core/animal/RecognitionRules.java`
- Create: `core/exhibit/AnimalPoint.java`, `core/exhibit/ExhibitGrouping.java`
- Create: `core/choice/ExhibitOption.java`, `core/choice/ExhibitChoice.java`
- Test: matching JUnit classes

**Produces:**
- `record RecognitionFacts(boolean includeTagged, boolean excludeTagged, boolean boss, boolean animalClass, boolean waterAnimalClass, String spawnCategory)`; `RecognitionRules.isExhibitAnimal(RecognitionFacts)`.
- `record AnimalPoint(UUID id, String species, double x, double y, double z)`; `ExhibitGrouping.group(List<AnimalPoint>, double linkDistance) -> List<List<AnimalPoint>>`; `ExhibitGrouping.match(List<Set<UUID>> previous, List<Set<UUID>> current) -> int[]` (index of the previous group each current group continues, or -1).
- `record ExhibitOption(Set<String> species, double distance, boolean recentlyVisited)`; `ExhibitChoice.weight(ExhibitOption, Set<String> seen, boolean enthusiast)`; `ExhibitChoice.pick(List<ExhibitOption>, Set<String> seen, boolean enthusiast, double roll) -> int`.

### Task 2: Census, species and tags

**Files:**
- Create: `animal/AnimalRecognition.java`, `animal/SpeciesData.java`, `animal/ZooDataMaps.java`, `animal/AnimalCensus.java`, `animal/Exhibit.java`, `animal/ZooCensus.java`
- Create: `data/zoocraft/tags/entity_type/exhibit_animals.json`, `not_exhibit_animals.json`
- Test: `gametest/AnimalGameTests.java`

**Produces:**
- `AnimalRecognition.isExhibitAnimal(Entity)`, `AnimalRecognition.species(EntityType<?>) -> ResourceLocation`, `speciesName(...) -> Component`.
- `Exhibit`: stable `id`, `species()`, `animals()`, `centre()`, `viewingSpots()`, `viewCount`, `markUnreachable(long until)`, `isUnreachable(long now)`, `markReached(long now)`.
- `AnimalCensus.of(Zoo) -> ZooCensus` (cached, refreshed every `censusIntervalSeconds` on server tick for open zoos and on demand for the dashboard); `ZooCensus.animals()`, `exhibits()`, `species()`.

GameTests: pig, cow and cod recognised, villager and iron golem not; baby and adult pig count as one species; census groups two separated pens as two exhibits.

### Task 3: Viewing, choice and comments

**Files:**
- Modify: `visitor/VisitorExploration.java`, `visitor/Visitor.java` (runtime viewing state), `visitor/VisitorController.java`
- Create: `animal/Viewing.java`
- Test: `gametest/ViewingGameTests.java`

**Produces:**
- `Viewing.canSee(Level, Vec3 eye, Entity animal, int radius)`: within radius horizontally, 3 vertically, one ray not blocked by any block with `canOcclude()`.
- Visitors choose exhibits with `ExhibitChoice`, walk to a viewing spot, linger, count views, gain interest and satisfaction for new species, and say the comments from spec 8.6 with at most one comment per 15 seconds.

GameTests: animal behind stone not seen, behind glass seen; a visitor in a zoo with a pen of pigs ends up having seen the pig species.
