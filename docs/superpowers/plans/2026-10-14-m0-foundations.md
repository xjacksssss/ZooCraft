# M0 Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A NeoForge 1.21.1 mod project that builds, loads, and has working JUnit and GameTest harnesses, with SmartBrainLib and JTS wired in.

**Architecture:** ModDevGradle project based on the official NeoForge 1.21.1 MDK. Pure-logic code is tested with JUnit 5. In-world behaviour is tested with NeoForge GameTests run by `runGameTestServer`. JTS is bundled with jar-in-jar. SmartBrainLib is a required, non-bundled mod dependency.

**Tech Stack:** Java 21 (Temurin 21.0.12), Gradle 9.2.1 wrapper, ModDevGradle 2.0.148, NeoForge 21.1.251, Parchment 2024.11.17, SmartBrainLib-neoforge-1.21.1 1.16.11, JTS 1.20.0, JUnit 5.

**Spec:** `docs/superpowers/specs/2026-10-14-phase1-prototype-design.md`

**Execution note:** The user asked for uninterrupted execution of all milestones. Plans list exact files, interfaces and tests; code is written during execution, test first.

## Global Constraints

- Minecraft 1.21.1, NeoForge 21.1.251, Java 21.
- Mod ID `zoocraft`, base package `com.zoocraft`.
- Project lives in `C:\dev\ZooCraft`, never in OneDrive.
- British English in all player-facing text and docs.
- SmartBrainLib is a required dependency and must not be bundled (ATM10 already ships it).
- JTS is bundled through jar-in-jar.

## Review Focus

- Build run with the wrong JDK on PATH (JDK 17 is the system default): the Gradle toolchain must select JDK 21 regardless. Pinned through `org.gradle.java.installations.paths` in the user-level `gradle.properties`.
- GameTest server with no tests crashes: the sample GameTest must be registered so `runGameTestServer` exits 0.
- Loading alongside ATM10's own SmartBrainLib must not produce a duplicate mod error: we never bundle SBL.
- JTS classes must be available at runtime in production (not just in dev): checked by inspecting the built jar for `META-INF/jarjar/`.
